# Paredes Vivas: El Templo de los Números

Juego de puzles por turnos al estilo Pokémon de GBA, hecho en **Godot 4.4** para Ingeniería de Software II (SENA).

| Carpeta / archivo | Contenido |
|---|---|
| `proyecto_godot/` | El juego (abrir `project.godot` con Godot 4.4) |
| `proyecto_godot/docs/ARQUITECTURA.md` | Patrones de diseño, SOLID y pruebas |
| `proyecto_godot/docs/uml/` | Diagramas UML |
| `00_DISENO_V2_LEER_PRIMERO.md` | Documento de diseño del juego |
| `diseno_pantallas/` | Bocetos de las pantallas |

## Jugar
1. Descargar Godot 4.4 (https://godotengine.org/download/archive/4.4.1-stable/).
2. Abrir Godot → **Importar** → seleccionar `proyecto_godot/project.godot`.
3. Presionar **F5**.
